# Admin Panel

Tecnología: Laravel + Livewire + Alpine + Tailwind.

## Módulos
- Dashboard;
- Usuarios;
- Foods;
- Nutrients;
- Portions;
- Aliases;
- Barcodes;
- Dominican curation;
- Recipes;
- AI analyses;
- AI corrections;
- Low-confidence queue;
- Failures;
- AI cost;
- Subscriptions;
- Notifications/configuration.

## Reglas
- roles/permissions;
- audit para acciones sensibles;
- nunca manipular catálogo normalmente por SQL directo;
- preservar source traceability.
