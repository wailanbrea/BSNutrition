# BSNutrition

Aplicación integral de nutrición, conteo de calorías, seguimiento de macros/micronutrientes e inteligencia artificial (reconocimiento de platos, OCR de etiquetas y registro por voz).

## Estructura del Monorepo

- [`NutritionApp/`](./NutritionApp): Aplicación nativa Android (Kotlin, Jetpack Compose, Material 3, Room, Health Connect, CameraX).
- [`nutrition-backend/`](./nutrition-backend): API Backend en Laravel 11/13 (PHP 8.2+, MySQL 8.4 LTS, Sanctum, Pest).
- [`NutritionApp_AI_Execution_Plan/`](./NutritionApp_AI_Execution_Plan): Documentación y plan de ejecución de 17 fases.
